- Inicie o *Back In Time* pelo menu de aplicativos.
- Selecione um diretório de destino para os backups na aba *General* (unidade USB,
  diretório local, localização de rede…).
- Opcionalmente, selecione uma programação para backups automáticos (por exemplo, *Toda semana*).
- Na aba *Include*, adicione os arquivos/diretórios dos quais deseja fazer backup (por exemplo, Documentos,
  Música…).
- Salve suas configurações clicando em *OK*.
- Inicie a operação de backup.
